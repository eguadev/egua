# Lógica de Programação

## Introdução
Lógica de programação é a forma de estruturar o raciocínio para resolver problemas: organizar instruções em sequência, tomar decisões com base em condições e repetir tarefas com loops.

A lógica de programação gira em torno de algoritmos: sequências de passos que descrevem como resolver um problema, claros e precisos o suficiente para um computador executar.

Alguns conceitos ajudam a desenvolver essa lógica:

1. Sequência: A sequência é a ordem em que as instruções são executadas. Cada instrução é executada uma após a outra, seguindo uma ordem específica.

2. Decisão: A tomada de decisão envolve o uso de condicionais para verificar se uma determinada condição é verdadeira ou falsa. Com base no resultado, o programa pode executar diferentes conjuntos de instruções.

3. Repetição: A repetição é usada para executar um conjunto de instruções várias vezes. Ela permite que tarefas sejam automatizadas e que dados sejam processados de forma eficiente.

4. Decomposição: A decomposição envolve dividir um problema complexo em partes menores e mais gerenciáveis. Cada parte pode ser resolvida individualmente, simplificando o processo de solução como um todo.

5. Padrões de solução: Existem padrões comuns de solução para problemas recorrentes. Conhecer esses padrões pode ajudar na resolução mais eficiente de problemas, como o uso de loops para iterar sobre uma lista de elementos.

Resolver um problema bem passa por entendê-lo, identificar as entradas e saídas necessárias e planejar os passos para chegar lá.

## Um algoritmo do dia a dia

Antes de ver um algoritmo em código, vale entender que você já segue algoritmos todos os dias. Uma receita de bolo, por exemplo, é um algoritmo: uma sequência de passos que, se seguidos na ordem certa, sempre leva ao mesmo resultado.

1. Separe os ingredientes (entrada).
2. Misture os ingredientes na ordem indicada (sequência).
3. Se a massa estiver homogênea, leve ao forno; senão, continue misturando (decisão).
4. Espere o tempo de forno indicado, verificando o ponto a cada poucos minutos (repetição).
5. Retire o bolo pronto (saída).

Um programa de computador funciona do mesmo jeito: recebe uma entrada, segue uma sequência de instruções (algumas condicionais, algumas repetidas) e produz uma saída. A diferença é que essas instruções precisam ser exatas, porque um computador não interpreta ambiguidade.
